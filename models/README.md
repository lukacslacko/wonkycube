# Model versions

The latest owner-tested designs are the [64 mm Skewb v1.1 with trimmed tips](../designs/skewb-v1.1) and [64 mm Redi v4.3](../designs/redi-v4.3). These are separate mechanisms; their parts do not interchange.

The directory named `current` is retained from the first publication and contains
the **80 mm v4.2.1** files. It is kept intact so earlier hashes and reproduction
scripts remain valid. It is not the latest compact set, and its parts and hardware
do not interchange with v4.3.
