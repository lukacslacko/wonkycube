# Current printable set — v4.2.1

Use [the printing and assembly guide](../../docs/printing-and-assembly.md).

- `parts/`: core, C01–C08 and E01–E12, one each (21 puzzle STLs).
- `plates/`: two edge plates, two corner plates, a core plate, and an optional E12 comparison plate. Geometry only, in millimetres; use 100% scale.
- `calibration/`: assembly stand, fit coupon and the optional five-part single-axis fixture.
- `reference/`: assembled inspection model, mechanism-space arrays, dimensions, section drawings and four verification reports.
- `SHA256SUMS.txt`: checksums for the exact checked files in this folder.

The assembled 3MF is for inspection, not printing as a fused object. File IDs identify solved positions; keep those IDs associated with your printouts.

This publication export continues the 3 mm radial rounding through the inner track. It reuses the core and eight corners byte-for-byte from the earlier set. The owner reported a successful v4.2 print; this fresh v4.2.1 export has digital checks and has not separately been reported printed. See [validation](../../docs/validation.md).
